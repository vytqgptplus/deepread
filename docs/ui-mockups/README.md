# DeepRead UI Mockups

Các mockup giao diện cho dự án DeepRead theo phong cách ChatGPT 2026.

## Các màn hình

1. **Main Chat** (`main-chat.html`) - Giao diện chat chính với sidebar thư viện sách
2. **Follow Reading** (`follow-reading.html`) - Chế độ đọc theo với split-screen chat + sách
3. **Book Library** (`book-library.html`) - Thư viện sách với upload
4. **Mini Chat & Audio** (`mini-chat-audio.html`) - Mini chat và chế độ nghe sách

## Xem mockup

Mở file HTML trong trình duyệt để xem:
```bash
start main-chat.html
```
